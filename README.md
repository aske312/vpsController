# 312node.net PRO

312node.net PRO — self-hosted панель управления Linux VPS для мониторинга сервера, управления защищёнными подключениями и настройки сетевых маршрутов.

## Возможности

- мониторинг ресурсов, сети, служб и событий безопасности;
- WireGuard, AmneziaWG, Shadowsocks, VLESS, Hysteria2, TUIC, Trojan, OpenVPN и IKEv2;
- создание конфигураций, ссылок и QR-кодов для клиентских устройств;
- Mihomo, DNS-политики и маршрутизация трафика;
- relay-маршруты и дополнительные средства защиты;
- диагностика, обновление и восстановление приложения.

Профили Mihomo скачиваются и передаются по подписке только в формате YAML.
Используйте клиент с поддержкой Mihomo/Clash YAML. Экспорт профилей в JSON
для sing-box/Xray и URI-подписки удалены; старые настройки формата игнорируются.
При запросе удалённого формата или обращении распознанного клиента без поддержки
YAML сервер возвращает HTTP 410 с кодом `profile_format_retired` и инструкцией
перехода. Неизвестный формат возвращает HTTP 422 (`unsupported_profile_format`).
Ошибка не регистрирует устройство и не меняет профиль. Используйте клиент
Mihomo/Clash YAML и добавьте общую ссылку профиля заново; ключи менять не нужно.
Встроенный пресет блокировки рекламы удалён. DNS, защита от вредоносных доменов,
правила приватности и пользовательские правила маршрутизации настраиваются отдельно.

В подключениях доступны встроенные пресеты для 32 поддерживаемых сочетаний:
VLESS REALITY, VLESS/VMess/Trojan через TLS и CDN, WG/AWG, Shadowsocks,
Hysteria2 и TUIC. Сохранённые пользовательские пресеты остаются доступными.
REALITY автоматически получает согласованные target/SNI из списка 10 HTTPS-доменов;
для QUIC по умолчанию используется SNI с проверкой отпечатка применённого сертификата.
Обычный TLS/CDN использует подтверждённый домен VPS/CDN и его сертификат.
Произвольный внешний домен не заменяет имя сертификата вашего сервера.

«Резерв» выбирает первое доступное подключение по порядку приоритетов.
«Автовыбор» направляет новые соединения через доступный канал с минимальной
измеренной задержкой (без допуска 50 мс); уже открытые потоки продолжают работу
через прежний канал. «Вручную» переключается в клиенте Mihomo.

В редакторе профиля → «Защита» выбирается TUN или Proxy. Proxy выключает TUN
в подписке; приложения должны использовать локальный прокси Mihomo (порт 7890)
или системный прокси клиента. Настройка ОС и переопределения самого клиента
не переключаются сервером. Новые профили используют TUN; старые сохраняют свои
настройки до явного выбора режима.

В «Маршрутизации» доступны «По правилам» (VPN по умолчанию с прямыми исключениями) и «Только
выбранное» с прямым маршрутом по умолчанию. Для второго режима есть YouTube,
Telegram, Discord, WhatsApp, Instagram, Facebook, X, Signal, Viber, Snapchat,
Roblox, LinkedIn, Threads, Claude, ChatGPT, TikTok, Twitch.tv, Spotify, Reddit,
Netflix, Pinterest и персональные правила сайтов/приложений. Правила процессов доступны
для TUN на поддерживаемых настольных клиентах; в Proxy они не экспортируются.
Прямые персональные исключения имеют приоритет, прежние широкие bypass-пресеты
в режиме «Только выбранное» не применяются. Выборы сохраняются при смене режима.
Режимы переключаются компактными кнопками в заголовках. Фильтрация опасных
доменов, приватность и совместимость QUIC находятся в «Защите»;
в «Маршрутизации» находятся выбор DNS, правила маршрута и персональные исключения.
Telegram использует снимок официальных IPv4/IPv6-сетей от 2026-10-30; P2P-звонки
могут обращаться к адресам вне этого списка. Домены и сети сервисов обновляются
вместе с приложением, без загрузки дополнительных баз при запуске клиента.
Каталог использует небольшой проверенный набор доменов, а не целые списки
общих CDN. Для общих облачных платформ задаются только точные имена серверов.
Соединения к неизвестным IP, P2P-звонки и отдельные игровые серверы могут
требовать персонального правила приложения в TUN. Наличие сервиса в каталоге
не означает проверку всех функций его приложения на всех клиентах.
Векторные иконки сервисов находятся в `public/icons/apps`; источники и лицензия
сохранены рядом. Это локальные ресурсы, внешние запросы для иконок не нужны.
Доменные наборы взяты из закреплённого снимка domain-list-community (MIT);
лицензия находится в `protocol-images/mihomo/licenses`.
Для DNS по маршруту учитывается выбранный маршрут по умолчанию. Запросы,
маршрут которых определяется только по IP/процессу, могут использовать DNS
через VPN до выбора маршрута соединения. После сохранения обновите подписку.

## Требования

- Ubuntu Server 22.04, 24.04, 26.04 или Debian 12/13;
- архитектура `amd64` или `arm64` и systemd;
- от 1 ГБ оперативной памяти и 5 ГБ свободного места;
- root-доступ или пользователь с `sudo`;
- доступ сервера к GitHub и системным репозиториям.

Для новой установки рекомендуется Debian 13. Доступность отдельных протоколов зависит от ОС, архитектуры и ядра сервера и проверяется перед установкой модуля.

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/aske312/vpsController/installer/install.sh \
  | sudo bash -s -- --edition pro
```

Для работы панели по доменному имени заранее направьте A-запись на IPv4 сервера и откройте TCP-порты 80 и 443:

```bash
curl -fsSL https://raw.githubusercontent.com/aske312/vpsController/installer/install.sh \
  | sudo bash -s -- --edition pro --domain vpn.example.com
```

После завершения установки в терминале будут показаны адрес панели и данные для входа. Повторно вывести их можно командой:

```bash
sudo vps-control credentials
```

## Управление

```bash
sudo vps-control status
sudo vps-control restart
sudo vps-control verify
sudo vps-control update
```

## Удаление

Команда удаляет панель, её настройки и данные. Установленные системные пакеты сохраняются.

```bash
sudo vps-control uninstall --yes
```
