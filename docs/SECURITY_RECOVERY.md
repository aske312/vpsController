# Восстановление настроек защиты

Перед `vps-control secure` приложение создаёт зашифрованную точку восстановления
и проверяет снимок файлов SSH, sysctl, Fail2ban, firewall и состояний служб.
Если снимок не удалось проверить, усиление защиты не начинается.

При ошибке настройки приложение автоматически восстанавливает предыдущую
конфигурацию. Если восстановление не подтверждено или процесс прерван, новые
изменения блокируются. Для продолжения восстановления подключитесь по SSH:

```bash
sudo vps-control security-recover
```

Команда использует сохранённую точку текущей прерванной операции и общий замок
операций. При ошибке проверки или восстановления блокировка остаётся. Удалять
`/var/lib/vps-control/recovery/security-recovery.txt` вручную не требуется.
Если незавершённое восстановление относится к обновлению приложения, используйте
команду, указанную его диагностикой, вместо `security-recover`.

Точки и ключ хранятся в `/var/lib/vps-control/recovery` с доступом только root.
Снимок возвращает конфигурацию и прежние состояния служб; установленные системные
пакеты остаются. Архив конфигурации не является откатом версий пакетов ОС.
