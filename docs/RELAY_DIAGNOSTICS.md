# Проверка Relay в ROUTES

Раскройте адрес Relay в ROUTES, затем раздел «Перенаправления Relay». Выберите существующее подключение нужного протокола и нажмите «Проверить видео с VPS». Дождитесь окончания операции; повторное нажатие во время проверки не требуется.

PRO запускает отдельный протокольный клиент на VPS и направляет его через выбранное перенаправление. Проверяются полная передача видеоролика W3C Sintel и три запроса перемотки, два параллельно. Содержимое сравнивается с известным файлом и SHA-256. Ответ HTTP 200 и слушающий порт отдельно не подтверждают работоспособность.

В ROUTES показаны состояние порта, результат и время теста, переданные байты, активные сессии и ошибки. Agent 1.2 дополнительно сообщает UDP-пакеты в обе стороны, локальные отбрасывания, причину последней ошибки и время последнего ответа. Счётчики сбрасываются при перезапуске Agent и не являются измерением потерь во всей сети.

Тест идёт по пути **VPS → Relay → VPS или CDN → сайт с видео**. Для подтверждения доступа с телефона или компьютера нужна отдельная проверка с этого устройства. Это не запуск приложения YouTube и не проверка всех правил полного клиентского профиля.

Для подключения Mihomo используется фактический экспорт выбранного устройства. Если он не соответствует выбранному порту Relay, не может быть однозначно сопоставлен или требует отсутствующий клиент, результат останется неподтверждённым. Тест не меняет настройки и не использует прямой IP VPS вместо Relay. Действующие WireGuard/AmneziaWG peer не запускаются тестом во избежание перехвата пользовательской сессии.

Результат связан с параметрами подключения. После изменения конфигурации либо через час его актуальность не подтверждена — выполните новую проверку. Слушающий порт и успешный медиатест показываются раздельно.

В сведениях Agent отображается автообновление и результат последней проверки GitHub. Agent 1.2 проверяет обновления раз в сутки по умолчанию; старые Agent требуют однократной штатной переустановки. Обновление перезапускает Agent и может прервать активные соединения. Изменения этой функции в PRO сами по себе не обновляют удалённые Agent.
