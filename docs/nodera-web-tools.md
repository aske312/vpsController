# Интернет-инструменты Nodera

AI-agent 1.21 / Nodera 1.14 расширяют чтение публичных HTTPS-страниц:

- `web_search(query, sites?)` возвращает ссылки и поисковые описания.
- `web_read(url, focus?)` читает текст; тема `focus` выбирает релевантные фрагменты.
- `web_research(query, sites?)` ищет и параллельно читает источники для сопоставления.
- `web_extract(url, mode)` извлекает `headings`, `links`, `tables` или `metadata`.

В настройках «Интернет» сохраняются `web_extract_enabled` (по умолчанию true),
`web_max_sources` (1–5, по умолчанию 3), `web_read_chars` (2000–20000,
по умолчанию 14000) и прежние предпочтительные домены. Старый запрос сохранения
без новых полей сохраняет их текущие значения. Разрешение `web` и основной switch
«Интернет» продолжают ограничивать все эти инструменты. Отключённый парсинг
не предлагается модели и отклоняется при прямом вызове.

Парсинг ограничен 50 заголовками/ссылками, 5 таблицами и 20 строками таблицы;
объём результата ограничен настройкой чтения. Ограничение помечается `truncated`.
JavaScript не выполняется, найденные ссылки автоматически не открываются.
Загрузки используют прежнюю проверку публичных адресов, закрепление DNS,
проверку каждого перенаправления, таймауты и лимит размера ответа. Cookies и
авторизация не отправляются. Содержимое страниц остаётся недоверенными данными.

# Квота и баланс API

Для совместимых New API сервер читает остаток ключа из `/api/usage/token/`.
Дополнительно `/api/status` на том же проверенном HTTPS-origin запрашивается
без API-ключа. USD отображается только при явных `quota_display_type: "USD"`
и конечном положительном `quota_per_unit`.
`remaining_usd` относится к ключу; `balance_usd` — к `user_quota.total_available`
аккаунта. Отсутствие баланса обозначается «—», без подстановки остатка ключа.
Безлимитный ключ остаётся безлимитным; произвольные единицы не считаются долларами.
Конверсия соответствует [реализации New API](https://github.com/QuantumNous/new-api/blob/main/web/src/lib/currency.ts).
