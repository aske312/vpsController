# Контроль подписки Mihomo

В «Настройка профиля → Общее → Контроль подписки» доступны:

- **Скорость, Мбит/с**: один общий потолок для всех подключений и устройств профиля, отдельно для приёма и передачи.
- **Общий трафик, GB**: сумма приёма и передачи через VPN-сервер. 1 GB = 1 000 000 000 байт.
- **Дни использования**: непрерывный календарный срок с сохранения включённого ограничения.

Для каждого параметра есть **Unlimit — без ограничений**. Снятие одного ограничения не снимает остальные. Изменение количества дней сохраняет первоначальный момент начала срока. Чтобы начать новый срок, нужно сохранить Unlimit для дней, затем включить срок заново. Изменение имени, устройств, подключений и повторное скачивание подписки ничего не обнуляют.

При исчерпании объёма или срока сервер блокирует трафик всего профиля, включая уже открытые соединения. Сохранённый файл клиента не позволяет обойти ограничение. При увеличении квоты/срока или выборе Unlimit доступ возвращается без замены ключей. Клиенту может потребоваться повторное подключение.

Учитывается IP-трафик между сервером и целевыми адресами после аутентификации прокси, а для WireGuard/AmneziaWG — трафик расшифрованных peers. Прямой DIRECT-трафик устройства и внешние расходы Relay/CDN в квоту не входят. До первого сохранения контроля подписки исторический расход не восстанавливается из неполных старых наблюдений.

## Применение на сервере

Xray и sing-box направляют аутентифицированных пользователей профиля в выделенный outbound с постоянной меткой. Маркировка не меняет ключи, порты и Relay/CDN-маршруты. Shadowsocks определяется по cgroup принадлежащего профилю systemd-instance, исключая зашифрованную клиентскую сторону. WG/AWG определяются по tunnel-интерфейсу и внутреннему IP peer. Все эти источники используют одну kernel quota и два общих token bucket в отдельной nftables-таблице `inet vps_mihomo_limits`.

Ограничение скорости — policing: пакеты сверх заданной средней скорости отбрасываются. Возможны кратковременные bursts; это не гарантия минимальной скорости и не очередь сглаживания. С Unlimit rate-проверки отсутствуют.

Скрытые клиентские ограничения Hysteria2 для управляемого профиля заменяются адаптивным режимом; общий серверный лимит старого Hysteria2-listener не перекрывает политику подписки. Сервер включает `ignore_client_bandwidth`, чтобы старые подсказки скорости в сохранённом клиентском файле не задавали прежний Brutal-лимит. После переподключения клиент согласовывает адаптивный режим; обновление подписки также убирает устаревшие параметры из файла. Серверные ограничения действуют независимо от обновления клиента.

Сервис `vps-control-subscription-limits.service` сохраняет суммарные счётчики раз в секунду и при штатной остановке. При перезапуске менеджера/протокола kernel-счётчики продолжают работать; при перезагрузке ОС восстанавливается сохранённый расход. При внезапном отключении питания возможна потеря последнего интервала учёта. Изменение nftables-политики сохраняет значения счётчиков, а не начинает учёт заново. При обновлении правил возможна небольшая погрешность трафика между снятием счётчиков и атомарной заменой объектов.

Учёт и готовность отображаются в API профиля (`limits`, `limits_status`). Стандартный HTTP-заголовок `Subscription-Userinfo` передаёт клиенту объём и срок. Недоступный runtime не позволяет сохранить новую политику как успешно применённую. Неактуальное наблюдение отмечается как неизвестное. Transaction recovery восстанавливает прежнюю политику без отката уже учтённого расхода.

Установка/обновление управляемого Mihomo устанавливает nftables и независимый сервис учёта. Протоколы зависят от восстановления правил при старте; Xray получает CAP_NET_ADMIN для SO_MARK на поддерживаемых Linux-ядрах. Удаление компонента очищает только принадлежащую ему таблицу и systemd drop-ins; сохранённый учёт следует существующему режиму сохранения данных компонента.

## Проверка

`tests/api/test_subscription_limits.py` проверяет модель, общий scope, срок, сохранение расхода, client export и конфигурации протоколов. `tests/subscription_limits_smoke.py` проверяет реальные kernel quota, rate policing, изоляцию профиля и возврат доступа в одноразовом network namespace:

```bash
sudo unshare --net python tests/subscription_limits_smoke.py
```

Тест отказывается запускаться в основной network namespace хоста. Он не использует пользовательские credentials и внешний интернет.
