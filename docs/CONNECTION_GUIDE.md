# AmneziaWG

[Русский](#ru) · [English](#en)

## RU

Для подключения нужен персональный файл `.conf` от администратора.

1. Установите AmneziaWG из магазина приложений вашей системы.
2. Добавьте подключение через импорт полученного файла `.conf`.
3. Сохраните профиль, разрешите создание VPN-подключения и включите его.
4. Проверьте статус и открытие сайтов.

Используйте файл на одном устройстве, не изменяйте и не передавайте посторонним.
Если подключение не работает, проверьте обычный интернет, выключите VPN на
10 секунд и включите снова. Если ошибка повторяется, сообщите администратору
устройство и время ошибки, без содержимого конфигурации.
При потере устройства или утечке файла попросите отозвать доступ.

## EN

You need a personal `.conf` file from your administrator.

1. Install AmneziaWG from your system's app store.
2. Add a connection by importing the supplied `.conf` file.
3. Save the profile, allow creation of the VPN connection, and enable it.
4. Check the connection status and access to websites.

Use the file on one device. Do not edit it or share it with others.
If the connection fails, check normal internet access, turn the VPN off for
10 seconds, and reconnect. If the issue persists, tell your administrator
the device and time of failure, without sending the configuration contents.
If a device is lost or the file is exposed, ask for access to be revoked.
