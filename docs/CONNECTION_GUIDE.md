# Подключение устройств

1. В панели PRO установите Mihomo Core и нужные транспортные модули.
2. Создайте профиль и добавьте подключения.
3. Скопируйте ссылку подписки или отсканируйте QR-код в Nodera либо клиенте с поддержкой Mihomo/Clash YAML.
4. Обновите подписку и включите подключение.

Ссылка подписки даёт доступ к подключениям. Передавайте её только владельцу устройства.
После изменения настроек в панели обновляйте подписку клиента.

## Маршрутизация

В профиле выберите нужные DIRECT-исключения. «Реклама» и «Трекеры» включаются отдельно.
Для применения исключений используйте режим маршрутизации по правилам.

## Лимиты

В «Контроле подписки» задаются скорость, трафик и срок. Значение 0 означает отсутствие
ограничения. После исчерпания лимита доступ приостанавливается; после его увеличения
может потребоваться переподключение. DIRECT-трафик устройства в расход подписки не входит.

## Если подключение не работает

Обновите подписку, проверьте срок и лимиты. Для Relay откройте его карточку в разделе
«Сеть» и выполните доступную проверку. Проверка с устройства показывает доступность
из вашей сети. Не публикуйте ссылки подписок, ключи и полные диагностические отчёты.

## Восстановление защиты

Если панель сообщает о незавершённом восстановлении настроек защиты, подключитесь по SSH:

```bash
sudo vps-control security-recover
```

Для других ошибок следуйте указанию панели. Сохранённые точки восстановления вручную не удаляйте.
