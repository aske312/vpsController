# Подключение с помощью WireGuard (WG) и AmneziaWG (AWG)

Это руководство предназначено для человека, который получил готовый файл конфигурации с расширением `.conf`.

## Какой вариант выбрать

- **WireGuard (WG)** — рекомендуется для устройств с постоянным локальным подключением к интернету: домашний или офисный интернет по кабелю, Ethernet, роутер.
- **AmneziaWG (AWG)** — рекомендуется для смартфонов, планшетов и других устройств, которые часто работают через мобильную сеть.

Для обоих вариантов используется одно приложение — **AmneziaWG**. Если администратор уже прислал файл, самостоятельно менять тип подключения не нужно: установите AmneziaWG и импортируйте полученный файл.

## Перед началом

1. Сохраните полученный файл `.conf` на устройство.
2. Не открывайте файл в текстовом редакторе и ничего в нём не изменяйте.
3. Не пересылайте файл посторонним. Он является персональным ключом доступа.
4. Один файл следует использовать только на одном устройстве.

## Установите приложение

Установите **AmneziaWG** из магазина приложений вашей системы. Это приложение используется и для WG, и для AWG.

## Подключение WG

1. Откройте AmneziaWG.
2. Нажмите кнопку добавления подключения и выберите импорт из файла.
3. Найдите полученный файл `.conf` в папке «Загрузки» или «Файлы» и выберите его.
4. **Обязательно включите галочку «Обфускация».**
5. Сохраните подключение.
6. Разрешите приложению создать VPN-подключение, если система задаст такой вопрос.
7. Включите переключатель рядом с новым подключением.

## Подключение AWG

1. Откройте AmneziaWG.
2. Нажмите кнопку добавления подключения и выберите импорт из файла.
3. Найдите полученный файл `.conf` в папке «Загрузки» или «Файлы» и выберите его.
4. Сохраните подключение.
5. Разрешите приложению создать VPN-подключение, если система задаст такой вопрос.
6. Включите новое подключение.

## Как понять, что всё работает

- В приложении переключатель подключения включён.
- Рядом с подключением отображается статус «Активно» или появляются данные о переданном трафике.
- Интернет-сайты открываются как обычно.

## Если подключение не работает

1. Убедитесь, что на устройстве работает обычный интернет.
2. Выключите подключение, подождите 10 секунд и включите снова.
3. Проверьте, что импортирован именно полученный файл и его содержимое не менялось.
4. Перезагрузите устройство.
5. Если проблема осталась, сообщите администратору название устройства, тип подключения WG или AWG и примерное время ошибки. Не отправляйте содержимое файла конфигурации в открытый чат.

## Важно

Если устройство потеряно, продано или файл конфигурации попал к постороннему человеку, сразу сообщите администратору. Старый доступ необходимо отозвать и создать новый.
