# Подключение устройств через Mihomo

1. Установите Mihomo Core и нужные транспортные модули в панели PRO.
2. В разделе Mihomo создайте профиль и настройте его каналы.
3. Скопируйте ссылку подписки или отсканируйте QR-код в приложении с поддержкой
   Mihomo/Clash YAML. Для каждого устройства используйте отдельную регистрацию.
4. Обновляйте профиль по той же ссылке подписки. Ссылка содержит данные доступа;
   передавайте её только владельцу устройства.

Для Relay выберите адрес Relay в канале Mihomo; для CDN выберите «Вход в CDN».
Порт назначается автоматически, ключи и параметры протокола сохраняются.
Проверяйте доступность подключения из клиентской сети.

В Nodera доступен подбор каналов: клиент проверяет каналы, затем предлагает
принять подготовленный профиль, отказаться или откатить предыдущий выбор.

Отдельное создание подключений Direct удалено из PRO. Ранее созданные данные
и службы не удаляются автоматически при обновлении. Каналы внутри подписок
Mihomo, включая прямое подключение к VPS, продолжают поддерживаться.

- [Диагностика Relay](RELAY_DIAGNOSTICS.md)

## Очистка Direct после перехода на PRO через Mihomo

Для полного удаления прежних управляемых Direct-служб, их подключений и ключей:

```bash
sudo vps-control direct-cleanup --permanent
```

Операция требует внешнего доступа к панели и подтверждённого владения компонентами.
Она проверяет все цели до удаления, затем останавливает Direct и очищает его данные.
Повторный запуск продолжает очистку оставшихся компонентов. Профили, подписки,
транспортные службы Mihomo и используемые ими общие пакеты сохраняются.
Без `--permanent` удаление не начинается. Автоматически при обновлении оно не выполняется.
Настройки DNS профилей находятся в Mihomo; прежний редактор Direct DNS в «Сети» убран.
