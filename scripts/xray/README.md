# Ядро Xray в поставке vpsController

`scripts/build-xray.sh` собирает официальный Xray v26.3.27 из коммита
`d2758a023cd7f4174a5a5fa4ff66e487d4342ba0`. Архив исходников проверяется
по SHA-256. Версия Go для CI закреплена в workflow.

Единственное изменение исходного обработчика: вызов `first.ReadFrom(conn)`
заменён на `readFirstTrojanRequest(conn, first)`. Реализация и тесты находятся
рядом с этим документом. Если первое чтение содержит только часть возможного
Trojan-заголовка, функция дочитывает 58 байт в пределах прежнего handshake
deadline. Проверка пароля, CRLF, доступов и маршрутизация остаются в обработчике
Xray. Не-Trojan-префиксы передаются прежнему fallback без ожидания.

Это модифицированная сборка, обозначенная `vpsController-trojan-fragment-v1`,
а не официальный бинарный релиз XTLS. Direct и Mihomo устанавливают её из
проверенного пакета приложения. Обновление компонента не должно подменять её
официальным ядром без этого исправления.

Сборка: Go 1.26.10, Linux amd64/arm64, `bash scripts/build-xray.sh api/bin/xray`.
Сборщик запускает регрессионные Go-тесты, проверяет маркер и создаёт SHA-256
бинарника. Неизменённый upstream source archive и лицензия MPL-2.0 включаются
в готовый пакет; изменённые файлы и точное преобразование поставляются в
`scripts/xray/` и `scripts/build-xray.sh`. Исходники upstream:
https://github.com/XTLS/Xray-core/tree/d2758a023cd7f4174a5a5fa4ff66e487d4342ba0
