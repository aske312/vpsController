# Xray в поставке

Модифицированная сборка Xray v26.3.27, обозначенная `vpsController-trojan-fragment-v1`.
Отличается от официального бинарного релиза исправлением обработки фрагментированного
Trojan-заголовка. Изменённые файлы и тесты находятся в этом каталоге.

Исходники: https://github.com/XTLS/Xray-core/tree/d2758a023cd7f4174a5a5fa4ff66e487d4342ba0

Сборка: `bash scripts/build-xray.sh api/bin/xray`. Исходный архив, лицензия MPL-2.0
и изменения поставляются вместе с приложением.
