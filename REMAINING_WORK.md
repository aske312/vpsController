## 4. Критерии завершения MVP

MVP можно считать введённым в эксплуатацию, когда:

- [ ] четыре обязательных Debian 13 стенда пройдены;
- [ ] обе редакции устанавливаются на amd64 и arm64;
- [ ] production и test каналы не смешиваются;
- [ ] неправильные архивы отклоняются без остановки рабочей версии;
- [ ] автоматический откат проверен на практике;
- [ ] Light сохраняет простой WG/AWG-сценарий;
- [ ] PRO сохраняет Mihomo, DNS и relay-функциональность;
- [ ] нет открытых критических и высоких дефектов;
- [ ] `installer` назначен основной веткой.

## 5. Отложено и не блокирует MVP

Эти задачи не нужно включать в текущий цикл стендовых проверок:

- подписка и лицензирование PRO;
- автоматическая миграция Light → PRO;
- перенос настроек между редакциями;
- ручной откат production-версии в течение семи дней;
- интерфейс управления сохранёнными версиями;
- дополнительное подписание релизных архивов;
- расширение списка официально поддерживаемых ОС.

Для каждой из этих функций потребуется отдельный план, реализация и тестирование. Они не должны задерживать проверку и запуск текущего разделения Light/PRO.

## 6. Ближайшее действие

Подготовить Debian 13 `arm64` и повторить L-R/P-R, затем выполнить Ubuntu smoke-tests. Для PRO отдельно нужны делегированный тестовый домен для DNS/relay/CDN и полный кликовый UI-прогон внутренних вкладок при доступном браузерном управлении. На `vps-6` оставлена чистая актуальная Light production; стенд `vps-3` не относится к этой разработке и не используется.
